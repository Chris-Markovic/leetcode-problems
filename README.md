# LeetCode Problems

My solutions to LeetCode problems, written in Python 3.

I'm trying to solve at least one problem every day to practice algorithms and data structures and to get better at problem solving. Each file has my solution and its time complexity at the top.

## Structure

Solutions are sorted by difficulty:

```
Easy/
Medium/
Hard/
```

Each file is named after the problem number and title, for example Easy/1.TwoSum.py.
